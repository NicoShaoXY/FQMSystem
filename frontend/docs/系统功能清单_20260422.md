### 2.2 市场概览 — MarketOverview

- **指数行情**：东方财富实时数据（沪深300、上证、创业板等）
- **市场统计**：涨跌停数、成交额、涨跌比

- **新闻舆情**：新闻舆情聚合，含尧帝交易信号标注
- **智能预测**：尧帝主分支（40%）+ 活跃分支（30%）加权预测
- **跨市场数据**：黄金、原油（部分数据源待完善）

### 2.3 舜帝交易系统 — Holding

- **持仓展示**：实时持仓、持仓成本、浮动盈亏、单日盈亏
- **交易执行**：买入/卖出下单、全部卖出
- **风险指标**：夏普比率、最大回撤、预期收益、市场情绪
- **调仓建议**：基于量化模型生成持仓调整建议
- **持仓分组**：按板块/概念自动分类展示
- **历史持仓**：完整交易历史记录查询

### 2.4 红皇后对抗系统 — RedQueen

- **对抗样本库**：累积49,141个对抗样本，16个分支
- **对抗训练**：adversarial training，触发条件：效果下降 ≥2%
- **自动回滚**：效果下降3.16%时自动回滚5个分支
- **技术指标模型**：150+个模型，涵盖MACD/KDJ/BOLL/CCI/DMI/ATR/RSI/WR等
- **演化控制**：启停控制、批量演化、新策略生成
- **Bug追踪**：演化过程中bug自动记录与修复

### 2.5 黑天鹅检测 — BlackSwanHistory

- **实时扫描**：历史黑天鹅事件记录（暴跌日统计）
- **风险预警**：大幅下跌预警
- **防御建议**：触发防御机制时的应对策略

### 2.6 自主控制系统 — AutonomyControl

三种运行模式：

| 模式 | 说明 |
|------|------|
| 手动模式 (manual) | 完全人工决策，系统仅提供建议 |
| 半自主模式 (semi) | 系统给出操作建议，人工确认后执行 |
| 自主模式 (autonomous) | 系统自动决策执行，风险内自主运行 |

- **紧急止损**：一键触发，紧急清仓
- **安全边界**：单笔限额、总仓限制、波动率熔断
- **操作日志**：所有修改操作记录可查
